プライバシーポリシー

桃尻くびれちゃん（以下「運営者」）は、登山記録アプリ「YAHHO」（以下「本サービス」）における利用者情報を次のとおり扱います。位置情報は記録中に限り取得し、緯度・経度はサーバーに送りません。

1. 取得する情報

区分具体的な情報取得方法
アカウント情報利用者 ID、ユーザー名、ユーザーID（@から始まる名前）、アカウント連携時に Apple・Google から受け取る識別子とメールアドレス（Apple で「メールを非公開」を選んだ場合は中継用アドレス）利用者 ID は初回起動時に自動で発行、連携情報は Apple・Google から受領、ユーザー名は利用者が入力
プロフィールアイコン画像、自己紹介利用者が任意で入力
位置情報緯度・経度、標高、時刻記録中に端末の GPS から取得（画面を閉じている間も含む）。端末内にだけ保存
記録データ山行日、山名、ルートの形、距離、獲得標高、所要時間、写真、メモ、ひとことタグ、同行者利用者が入力・アップロード
交流コメント、フォロー、ヤッホー、お知らせ、ブロック・通報の履歴利用に伴い記録
問い合わせ問い合わせ内容、返信先問い合わせ時

位置情報は、利用者が記録を開始してから終了するまでの間だけ取得し、端末内に保存します。記録を公開しても、サーバーに送るのは地図に重ねない「ルートの形」（縮めた線の図形）だけで、緯度・経度は送りません。写真は端末で縮小してから送るため、撮影地点などの付属情報（Exif）は含まれません。端末の設定で位置情報を許可しない場合、軌跡の記録はできませんが、手入力の記録などその他の機能は使えます。

本サービスは、広告用の識別子、解析ツール、クラッシュ収集ツールを使っていません。

2. 利用目的

  1. 記録の保存・表示、地図上への軌跡の描画、距離や標高差の計算
  2. フォロー、ヤッホー、コメント、ランキングなど利用者間の交流機能の提供
  3. 本人確認、ログイン、不正利用の防止
  4. 通報への対応、利用規約違反への措置
  5. アプリ内のお知らせの表示、問い合わせへの回答

運営者は、位置情報や記録データを広告の配信や第三者への販売には利用しません。

3. 記録の公開範囲

利用者は記録ごとに公開範囲を選べます。初期設定は「全体に公開」です。

公開範囲見られる人サーバーへの保存
自分だけ本人だけしない（端末内のみ）
友だちのみ投稿した人がフォローしている利用者する
全体に公開本サービスのすべての利用者する
  • 同行者として他の利用者を登録する場合、その人の名前が記録と同じ範囲に表示されます。
  • ランキングやプロフィールには、ユーザー名と集計値（登った山の数や獲得標高など）が他の利用者に表示されます。「自分だけ」の記録は集計に含めません。

4. 第三者への提供

運営者は、次の場合を除き、本人の同意なく個人データを第三者に提供しません。

  1. 法令に基づく場合
  2. 人の生命、身体または財産の保護のために必要で、本人の同意を得ることが困難な場合
  3. 国の機関や地方公共団体が法令の定める事務を行うことに協力する必要がある場合
  4. 事業の承継に伴って提供する場合

利用者が公開範囲を設定して他の利用者に記録を見せることは、利用者自身による公開であり、運営者による第三者提供には当たりません。
